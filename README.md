# IBS+ DETOX COLON — صفحة هبوط مغربية للراحة الهضمية

صفحة هبوط (Landing page) بالدارجة المغربية، mobile-first، مبنية باش تكون **جاهزة للإنتاج**:
HTML + CSS + JS خفيف بلا أي مكتبة خارجية، بلا طلبات للشبكة (الخطوط محلية)، وموجهة للتحويل
عبر **الدفع عند الاستلام (COD)**.

- **اسم المنتج:** IBS+ DETOX COLON (كتبان بالحروف اللاتينية كيفما هي على العلبة، مع عزل
  ثنائي الاتجاه `dir="auto"` باش ما تتقلبش وسط النص العربي).
- **الصورة الرسمية:** `assets/img/product.png` — كاينين جوج «بلاصات» (hero + قسم المنتج)
  كيتعمرو بـ **نفس** الملف. التصميم ما كيبدّلش العلبة، ما كيصاوبش موك أب جديد، وما كيغيّرش اللوگو.

---

## 1) كيفاش تشوف الصفحة

```bash
# أي سيرفر ستاتيك كيخدم
python3 -m http.server 8080 --bind 0.0.0.0 --directory .
# من بعد حلّ: http://localhost:8080/
```

الصفحة ما كتحتاجش build ولا npm. كافية تفتح `index.html` (لكن استعمل سيرفر باش الخطوط
والصور يتحمّلو مزيان).

---

## 2) هيكل الملفات

```
index.html                 ← كل المحتوى + الأيقونات (SVG sprite) + 12 قسم
assets/css/styles.css       ← نظام التصميم كامل (tokens + كومبوننتات)
assets/js/app.js            ← CONFIG + اختيار الباقة + الفاليداسيون + الـ sticky UI
assets/fonts/               ← خط Cairo (variable, woff2) — محلي بلا CDN
assets/img/                 ← تصاور lifestyle مغربية (طبيعية، بلا تخويف)
tools/smoke-test.mjs        ← تيست آلي للـ DOM والسلوك (jsdom)
```

---

## 3) كيفاش تحط صورة المنتج

**الطريقة 1 — الدائمة (المستحسنة للمنتاج):**

1. حط الصورة ف `assets/img/product.png` (PNG بخلفية شفافة، 1000×1400px ولا أكثر).
2. المسار **دابا مربوط** ف `assets/js/app.js`:

```js
brandName:    'IBS+ DETOX COLON',
productImage: 'assets/img/product.png',
```

الصورة كتبان تلقائياً فبلاصتين (hero + قسم المنتج) مع ظل واقعي وجودة استوديو.
ما كاين حتى فلاش ديال صورة مكسورة: التحميل كيتسنّى قبل العرض، وإلا ما لقاش الملف كترجع
البلاصة الرسمية بلا ما يتخربق التصميم.

**الطريقة 2 — المعاينة السريعة:**
من الصفحة، زر **«حمّل صورة المنتج»** كيخليك تشوف أي صورة دابا (كتبقى غير فالمتصفح، ما كتتسجّلش فالكود).

نفس الشي لسميّة المنتج: عمّر `brandName` وقد تبدّل تلقائياً فكل البلاصات (الهيدر، العناوين، الأسئلة، الفوتر).

## 4) المعطيات اللي خاصها تأكيد من البراند (ماشي مصنوعة)

كل شي تحت فـ `CONFIG` ف `assets/js/app.js`. القيم الافتراضية مختارة **باش ما تكذبش**:

| المعطى | الافتراضي | شنو كيدير |
|---|---|---|
| `brandName` | `'IBS+ DETOX COLON'` | الاسم الرسمي (مربوط) |
| `productImage` | `'assets/img/product.png'` | مسار الصورة الرسمية (مربوط) |
| `reviews` | `[]` | **بلا آراء مصنوعة** — كتبان 3 بلاصات فارغة بصدق |
| `stockLimited` | `false` | قسم «الكمية محدودة» مخفي تماماً |
| `inspectionBeforePayment` | `false` | جملة «شوف المنتوج قبل ما تخلص» مخفية |
| `showPackRibbons` | `true` | شيل «الأكثر اختياراً» / «أفضل قيمة» إلا ما عندكش أساس |
| `deliveryTime` | `''` | مدة التوصيل الحقيقية (كتبان فملخص الطلب) |
| `orderEndpoint` | `''` | endpoint ديال الطلبات (POST JSON) |

### كيفاش تزيد آراء حقيقية

```js
reviews: [
  { name: 'سعاد', city: 'الدار البيضاء', rating: 5, verified: true,
    text: 'الرأي كيفما وصل من الزبونة، بلا ما نبدلوه.' },
  { name: 'كريم', city: 'مراكش', verified: false,
    text: 'رأي بلا تقييم بالنجوم حيت ما تأكدش.' },
],
```

النجوم كتزاد غير ملي تعمّر `rating`، و«شراء متأكد» كتزاد غير ملي `verified: true`.

### باقي البلاصات اللي مكتوب فيها توكن (`عنوان مائل + خط تحتي مقطّع`)

- اسم المكوّن + الكمية + الدور المعروف ديالو (3 كارتات فقسم المنتج) — **خاصهم يجيو من الملصق
  الرسمي** (الملصق كيبيّن غير الحجم 30 كبسولة والاسم IBS+ DETOX COLON، وباقي المكوّنات خاصها
  تصويرة واضحة ديال الجيهة التانية باش ما نكتبوش شي حاجة ما كايناش).
  المعلومة الوحيدة المؤكدة (30 كبسولة) راه مكتوبة فقسم المنتج.
- `سياسة التوصيل الرسمية` فالسؤال الأخير فـ FAQ.
- `مدة التوصيل الرسمية` فالسؤال ديال المدة.
- روابط السياسات فالفوتر (`data-policy`) — خاصهم يتربطو بالصفحات الرسمية.

## 6) نظام التصميم

- **الألوان:** ivory `#FBF9F4` · beige `#ECE4D5` · emerald `#0A3A2A → #1B7D57` · sage `#CFDFD0` · charcoal `#1C2420`.
- **الخط:** Cairo Variable (وزن 200–1000)، محلي، بلا Google Fonts. العناوين 800، النصوص 400، سطور 1.85–1.95.
- **المقاسات:** عمود أقصى 480px (إطار ديال الموبايل فوق الديسكتوب)، radius 16–26px،
  ظلال خفيفة بزاف (3 مستويات)، بلا gradients قوية.
- **Spacing:** padding 20px، الفواصل بين الأقسام 60px، بطاقات بـ gap 12–16px.
- **RTL أصلي:** كل شي بـ logical properties (`inset-inline`, `padding-inline`)، المستند `dir="rtl"`.

---

## 7) شنو **ما** كاينش فالتصميم (بجهد مقصود)

- ❌ بلا scarcity وهمية: بلا countdown، بلا «باقي 3 قطع»، قسم الكمية مخفي افتراضياً.
- ❌ بلا آراء مصنوعة / أسماء ومدن وهمية / screenshots واتساب مزيّفة.
- ❌ بلا «100% علاج طبيعي»، بلا «بدون أعراض جانبية»، بلا وعود شفاء.
- ❌ بلا صور مرعبة (مصارين، مستشفيات، مرض شديد) — تصاور حياة عادية مغربية.
- ✅ تنبيه واضح: المنتج **مكمّل غذائي** وماشي دواء وماشي بديل على الطبيب.
- ✅ تأكيد إن النفخة ما كتعنيش بالضرورة القولون العصبي.

هادي ماشي غير حماية قانونية — هادي هي اللي كتبني الثقة وكتخرّج الصفحة من شكل
«صفحة أفلييت رخيصة».

## 8) الجودة التقنية

- **الاستمارة:** فاليداسيون ديال الاسم/الهاتف المغربي (`06/07/05...` ولا `+212`)/المدينة، مع رسائل خطأ بالدارجة.
- **الإرسال:** كيدير POST JSON لـ `orderEndpoint` إيلا كان معمّر، وإلا كيعرض حالة تأكيد محلية (وضع العرض) مع `console.info`.
- **الوصولية:** HTML دلالي، `label` مربوطة، `aria-pressed` على الباقات، `aria-live` على الآراء ورسالة الخطأ،
  focus-visible واضح، ودعم `prefers-reduced-motion`.
- **الأداء:** 0 مكتبات خارجية، خطوط variable محلية (2 ملفات ≈ 65KB)، صور lazy + `aspect-ratio` (بلا CLS).

### تيست آلي

```bash
npm i jsdom            # مرة وحدة
node tools/smoke-test.mjs
```

كيتحقق من: الأقسام، اللغة/RTL، الأقسام المشروطة، الآراء، الباقات، الفاليداسيون، الإرسال،
وغياب العبارات الممنوعة والنصوص الإنجليزية الظاهرة.

## 9) الخطوات الجاية

1. **ملف الصورة الرسمية** — حطّو ف `assets/img/product.png` (المسار مربوط، ما خاصكش تبدل الكود).
2. المكوّنات والكميات من الملصق الرسمي (3 كارتات).
3. الآراء الحقيقية (`reviews`) — وإلا نحيّدو القسم كامل.
4. سياسة التوصيل/الإرجاع الحقيقية + المدة + واش المعاينة قبل الدفع متوفرة.
5. رابط API ديال الطلبات (`orderEndpoint`) باش الطلبات تمشي مباشرة للـ CRM.
6. Pixel/TikTok CAPI + Google Analytics إيلا كنتو خدامين بيهم (المكان واجد فـ `<head>`).
